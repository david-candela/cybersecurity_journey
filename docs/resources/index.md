# Resources

Curated tools, platforms, and references I find useful on my cybersecurity journey.

---

## Learning Platforms

| Platform | Description |
|---|---|
| [TryHackMe](https://tryhackme.com) | Hands-on cybersecurity training through real-world labs |
| [Hack The Box](https://hackthebox.com) | Penetration testing labs and challenges |
| [CyberDefenders](https://cyberdefenders.org) | Blue team training with real-world investigations |
| [Splunk Free Training](https://www.splunk.com/en_us/training/free-courses/overview.html) | Free courses for learning Splunk fundamentals |

## Analysis Tools

| Tool | Use Case |
|---|---|
| [CyberChef](https://gchq.github.io/CyberChef/) | Data encoding, decoding, defanging, and analysis |
| [VirusTotal](https://www.virustotal.com) | File and URL scanning against multiple antivirus engines |
| [Thunderbird](https://www.thunderbird.net) | Email client useful for opening and inspecting `.eml` files |
| [Wireshark](https://www.wireshark.org) | Network protocol analyzer for packet capture and analysis |
